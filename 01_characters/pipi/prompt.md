# 🐶 小皮 (Pipi / Little Pi) 角色固定提示詞

## 📌 角色特徵表 (Character Visual Sheet)

| 項目 | 特徵設定 | 英文關鍵詞 (Prompt Keywords) |
| :--- | :--- | :--- |
| **品種 / 外觀** | 紅貴賓 / 泰迪熊貴賓犬 | Red toy poodle, teddy dog, curly poodle fur |
| **毛色與毛質** | 濃郁紅褐色/肉桂色，捲曲蓬鬆，胸前有一小撮白毛 | Cinnamon brown curly fluffy fur, white patch on chest |
| **五官表情** | 大黑圓眼（水潤高光）、深棕小鼻、粉紅小舌頭常微吐 | Big glossy black button eyes, dark button nose, cute pink tongue sticking out |
| **體型比例** | Q版卡通身形、短萌腿、毛茸茸小球短尾 | Chibi proportions, short legs, fluffy bobtail |
| **固定配件** | 天藍色項圈 ＋ 銀色狗骨頭名牌（刻有 "Little Pi"） | Bright sky-blue dog collar with a silver bone-shaped name tag engraved "Little Pi" |

## 🎯 核心固定 Prompt (Core Character Prompt)

### 英文版 (適用於 Midjourney / Stable Diffusion / DALL-E)

```text
(masterpiece, best quality:1.2), 3D animation style, Pixar style, cute adorable red toy poodle named Little Pi, fluffy curly cinnamon brown fur, distinct small white fur patch on chest, big glossy dark eyes with reflections, cute dark brown nose, playful pink tongue sticking out, wearing a bright sky-blue collar with a silver bone-shaped name tag, cute bobtail, happy and energetic expression, soft studio lighting, octanerender, smooth 3D render, high detail, clean neutral background
```

### 負向提示詞 (Negative Prompt)

```text
(worst quality, low quality:1.4), realistic photo, human face, straight hair, deformed paws, extra legs, extra tail, missing collar, aggressive expression, scary, flat 2D sketch, blurry, watermark, bad anatomy
```
